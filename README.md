# Search-Img-React-Basico

Uma galeria interativa em React para buscar e exibir imagens de **animais** e **paisagens**, com filtragem via input de texto.  
Projeto ideal para portfólio de desenvolvedor júnior frontend.

---

## 📌 Visão geral

- O usuário digita um termo no campo de busca e a galeria exibe apenas as imagens cujo **nome** corresponde ao termo.  
- Dois modos de visualização: **Animais** ou **Paisagens**, selecionados por botões.  
- Cada imagem está associada a um objeto com `nome` (string) e `img` (caminho/import).  
- A interface é simples, responsiva e com lógica básica de estado em React.

---

## 🛠️ Tecnologias utilizadas

- React (com `create-react-app`)  
- HTML5 & CSS3  
- Hook `useState` para controle de estado  
- Métodos de array: `filter()` para busca + `map()` para renderização  
- Estrutura de projeto típica (`src`, `public`)  
- Deploy via GitHub Pages (configuração em `package.json` com `gh-pages`)
